# Chronomancy ☀️⏳

A **Solarpunk Temporal Operating System** bridging long-term academic and career commitments with zero-based minute-level day execution.

Built on the principle of **100% Offline-First, Zero-AI, Deterministic Logic**. No cloud dependencies, no hallucinating LLMs, and no subscription fees.

---

## 🧭 Core Pillars

1. **The 1,440-Minute Zero-Based Ledger**:
   - Like YNAB's *"Give every dollar a job"*, Chronomancy enforces *"Give every minute a job"*.
   - Audits unbudgeted leaks (doomscrolling) as **Time Overdrafts** that must be explicitly rebalanced from other envelopes.
2. **Real-World Temporal Friction**:
   - Explicitly accounts for commutes, walking buffers between classes, and post-travel decompression.
3. **Multi-Horizon Pipeline**:
   - Academic syllabi, recurring assignment rhythms, and partner deadline sharing.
   - Long-term certification pace tracker (e.g. AWS Solutions Architect hours remaining vs. weekly targets).
   - Dormant project incubator.
4. **The Grove (Gamified Focus Arboretum)**:
   - Deep work sessions plant trees that grow into mature flora.
   - Abandoning focus sessions or falling into unbudgeted leaks withers your plant into a **withered stump (`🥀`)**.
   - RPG grind attributes (INT for study, DEX for coding, WIS for certs).
5. **Solarpunk UI (Web & Mobile Responsive)**:
   - Clean, optimistic eco-futurism (sunlit parchment, living chlorophyll green, warm solar amber, terracotta transit connectors).
   - Desktop 3-pane command dashboard + Mobile floating glass dock.
